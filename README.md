## 📖 这是什么？

**考研学习链 (Kaoyan AI Study Chain)** 是一套面向考研学子的**数字化、工程化 AI 私人教师备考系统模板**。

传统使用大模型（ChatGPT、Claude、Gemini 等）备考经常遇到三大痛点：
1. **幻觉与超纲**：AI 经常随性自编题目，或者派发出超出考试大纲的偏题怪题；
2. **缺乏记忆与连续性**：多轮对话后 AI 会遗忘你之前的薄弱点、错题与做题节奏；
3. **缺少量化闭环**：不知道每天任务是否达标，缺少碎片时间高效复习的工具。

本项目借鉴现代软件工程的开发模式，将 **Agent 角色协议（AGENTS.md）**、**外置持久化记忆（External State）**、**白名单题源核验门禁（Source Verification）** 与 **自动化轻量 Web 看板（Static Site Generator）** 相结合，帮助考研人构建属于自己的高纪律、零幻觉、稳拿基本盘的数字化私教。

## 🔒 隐私与防泄露机制（Local-First 原则）

本项目采用严格的 **Local-First（本地优先）** 隐私保护架构：
- 仓库内仅提供架构规范、教学协议与 `.example.md` 模板文件；
- **个人隐私保护**：`.gitignore` 默认规则自动忽略您实际填写的个人学情文件（如 `今日任务.md`、`学员档案.md`、`当前进度.md`、`学情档案.md`）以及您每日在 `每日笔记/`、`每日作业/`、`错题本/` 下产生的做题记录；
- 无论您如何提交代码，您的个人复习隐私、错题明细与大体积 PDF 资料都**牢牢保留在本地，绝不会上传到 GitHub**。

## 🚀 新手引导配置 (3 分钟开箱指引)

### 第一步：克隆或下载项目模板

```bash
git clone https://github.com/<your-username>/kaoyan-study-chain.git
cd kaoyan-study-chain
```

### 第二步：个性化参数配置 (配置你的目标)

打开根目录的 [`AGENTS.md`](AGENTS.md)，在第 0 节填入你自己的备战信息：
- **目标院校**：例如 `清华大学` / `中山大学` 等；
- **报考专业**：例如 `085400 电子信息` / `081200 计算机科学与技术` 等；
- **初试日期**：填入当年考研初试日期（如 `2026-12-19`）；
- **目标分数矩阵**：根据自己的目标总分（如 360/380/400）设定数学、英语、政治、专业课的达标线。

> [!TIP]
> 如果你的考试科目不同（例如考数学一或数学三、考英语一、统考 408 计算机等），只需在对应科目目录（如 `01-数学/AGENTS.md`、`04-专业课/AGENTS.md`）中修改参考教材和题源白名单即可！

### 第三步：启用本地学情状态文件

为了让私教记录你的实际进度，将各科 `_状态/` 目录下的 `.example.md` 文件复制一份为实际工作文件（受 `.gitignore` 保护，不会被传到云端）：

```powershell
# 快速初始化四科状态文件（PowerShell 一键命令）
Get-ChildItem -Path . -Recurse | Where-Object { $_.Name -like "*.template.md" } | ForEach-Object {
    $target = $_.FullName.Replace(".template.md", ".md")
    if (-not (Test-Path $target)) {
        Copy-Item $_.FullName $target
        Write-Output "Initialized: $target"
    }
}
```

### 第四步：接入 AI 开启每日私教学习

无论你使用的是 **Antigravity**、**Cursor**、**Claude Code** 还是 **VS Code + 终端**：
1. 打开本仓库目录；
2. 输入口令 `学数学` 或 `数学报到`，AI 自动根据当天任务与薄弱点派发习题；
3. 完成解题后拍照或敲字输入，输入 `交作业`，AI 按步骤给分并反馈改进处方；
4. AI 会自动将你的掌握度和错题写入 `_状态/` 记忆中。

### 第五步：一键生成并部署专属移动端看板

项目内置自包含看板生成引擎，无需安装任何第三方 pip 包：

```bash
# 运行看板构建（Python 3.8+ 自带标准库即可）
python 05-考研看板/build.py
```

- 生成的 `docs/index.html` 即为完整的响应式移动端看板！
- **部署到 GitHub Pages**：
  - 在 GitHub 仓库 -> **Settings** -> **Pages** -> Source 选择 **GitHub Actions**；
  - 仓库内已内置 `.github/workflows/deploy-pages.yml`，每次 push 自动完成在线发布！
- 用手机浏览器打开部署后的网址 -> 点击 **添加到主屏幕**，即可随时随地像 App 一样翻阅今日任务、自测公式卡片。

## 📱 移动端自测看板核心功能

| 页签 | 功能特性 | 核心使用场景 |
|---|---|---|
| 📋 **今日** | 自动提取四科当日任务单、目标用时与完成状态勾选 | 晨起确认任务，夜间核对进度 |
| 🧠 **必背** | 公式默写卡、高频核心考点、重点长难句、核心定理速查 | ★ **碎片时间主力**：排队、通勤、睡前 |
| 🎯 **薄弱** | 章节掌握度阶梯雷达、错题重做队列（艾宾浩斯复现） | 每周复盘时定向爆破 |
| 📊 **数据** | 错因五分类分布饼图、计算失误量化指标、考研倒计时 | 阶段性调整复习重心 |

> **独创「👁 遮罩自测模式」**：在看板点击顶部“开启遮罩自测”，公式列与答案列会被斜纹遮挡，点击单元格逐个揭示，让碎片时间从“被动看书”变成“主动默写抽测”！

## 💬 常用私教交互口令

| 口令 | 作用 |
|---|---|
| `数学报到` / `学数学` | 启动今日数学模块，AI 调取档案并派发精选练习 |
| `英语报到` / `学英语` | 启动英语模块，开始长难句拆解或真题阅读定位 |

| `查漏` | 调取四科薄弱点雷达与待重做错题队列 |
