## 📖 这是什么？

**考研学习链 (Kaoyan AI Study Chain)** 是一套面向考研学子的**数字化、工程化 AI 私人教师备考系统**。

传统使用大模型（ChatGPT、Claude、Gemini、DeepSeek 等）备考经常遇到四大痛点：
1. **幻觉与超纲**：AI 随性自编缺少标准答案的题目，或者派发超出大纲范围的偏题怪题；
2. **缺乏记忆与连续性**：多轮对话后 AI 遗忘你之前的薄弱考点、错题记录与复习节奏；
3. **缺乏采分点闭环**：直接给出终极答案，缺乏步骤分、公式分与“错因五分类”追查；
4. **缺少移动端自测工具**：碎片时间（排队、通勤、睡前）难以高效进行公式与核心考点默写。

本项目借鉴现代软件工程的成熟架构，将 **Agent 私教协议（AGENTS.md）**、**外置状态机记忆（External State）**、**白名单题源抽题门禁（Source Verification）** 与 **自动化轻量 Web 看板（Static Site Generator）** 相结合，帮助考研人构建属于自己的高纪律、零幻觉、稳拿基本盘的数字化私教系统。

## 🔒 隐私与防泄露机制（Local-First 原则）

本项目采用严格的 **Local-First（本地优先）** 隐私保护架构：
- 仓库内仅公开架构规范、教学协议与 `*.template.md` 空白模板文件；
- **个人隐私保护**：`.gitignore` 规则自动忽略您实际填写的个人学情文件（如 `今日任务.md`、`学员档案.md`、`当前进度.md`、`学情档案.md`）以及您每日在 `每日笔记/`、`每日作业/`、`错题本/` 下产生的所有私人做题记录；
- 无论您如何提交代码，您的个人复习进度、做题草稿、错题明细与大体积 PDF 资料都**牢牢保留在本地，绝不会上传到 GitHub**。

## 🚀 用户本地化部署与快速上手流程 (3 分钟开箱)

### 环境依赖
- **操作系统**：Windows、macOS 或 Linux
- **Git**（版本管理）
- **Python 3.8+**（无需安装任何 pip 第三方库，全部使用 Python 标准库）

---

### 第一步：获取项目模板

在终端或命令行运行：

```bash
# 克隆本仓库到本地
git clone https://github.com/moyetian/kaoyan_chain.git my-kaoyan-chain
cd my-kaoyan-chain
```

*(也可以直接在 GitHub 点击绿色 **Code -> Download ZIP** 下载压缩包解压使用)*

---

### 第二步：一键初始化本地工作区 (推荐)

项目内置了跨平台的交互式初始化引导工具，无需手动逐个重命名模板：

```bash
# 运行初始化脚本 (Windows / macOS / Linux 通用)
python tools/init_workspace.py
```

> [!TIP]
> 脚本将自动引导您：
> 1. 一键将四科 `_状态/` 目录中的 `*.template.md` 实例化为本地受保护的 `*.md` 工作文件；
> 2. 交互式输入您的目标院校、专业、年份与四科目标分数，自动写入 `AGENTS.md`；
> 3. 立即自动编译生成您的第一版专属移动端看板 `docs/index.html`。
> 
> *如果您希望跳过问答、使用默认配置快速启动，可执行：`python tools/init_workspace.py --quick`*

---

### 第三步：个性化配置各科参数

打开工作区中的各科协议文件微调您的教材白名单：

1. **总控配置 [`AGENTS.md`](AGENTS.md)**：核对目标院校、报考专业、初试日期和目标分数矩阵；
2. **数学配置 [`01-数学/AGENTS.md`](01-数学/AGENTS.md)**：设定您所考的数学种类（数学一/数学二/数学三/396经济类联考）及常用参考书；
3. **英语配置 [`02-英语/AGENTS.md`](02-英语/AGENTS.md)**：设定英语一或英语二，设定阅读定位策略与作文功能句；
4. **政治配置 [`03-思想政治理论/AGENTS.md`](03-思想政治理论/AGENTS.md)**：确认选择题核心得分盘（38~42分）与大题答题规范；
5. **专业课配置 [`04-专业课/AGENTS.md`](04-专业课/AGENTS.md)**：填入您的专业课代码与全称（如 408 计算机综合、801 自动控制等），以及官方指定的参考教材版本。

---

### 第四步：接入 AI 开启每日私教闭环

本项目支持 **两种主流使用模式**：

#### 模式 A：Agent IDE 闭环模式 (最推荐 · 全自动化)
使用具备本地文件读写能力的 AI 工具（如 **Antigravity**、**Cursor**、**Claude Code**、**VS Code + Roo Code**）：
1. 在 AI 编辑器中打开本项目根目录；
2. 开启对话，输入口令（例如：`数学报到` 或 `学英语`）；
3. AI 自动读取工作区顶层 `AGENTS.md` 与子科目下的状态档案，为您从白名单中抽选今日训练题目；
4. 您在纸上解答后敲字或拍照上传，输入 `交作业`；
5. AI 自动按采分点分步打分、指出漏洞，并**自动将错题写入错题本、更新薄弱点雷达**！

#### 模式 B：网页版 AI 辅助模式 (零门槛 · ChatGPT / Claude / DeepSeek / Kimi)
如果您使用网页版对话：
1. 开启一个专属对话，首次将根目录 [`AGENTS.md`](AGENTS.md) 与目标科目的 `AGENTS.md` 复制发送给 AI 作为系统设定；
2. 每天复习时，复制对应科目 `_状态/今日任务.md` 和 `学员档案.md` 粘贴给 AI 发送 `[科目]报到`；
3. 学习完毕后，让 AI 输出更新后的学情状态表格，复制回本地保存。

---

### 第五步：移动端自测看板查看与多端同步

#### 1. 本地直接预览
双击工作区中的 [`docs/index.html`](docs/index.html)，即可直接在任何现代浏览器中打开清新整洁的自测看板！

#### 2. 同局域网手机浏览 (无需云端)
在项目根目录下启动轻量级本地服务：
```bash
python -m http.server 8080 --directory docs
```
查看您电脑的局域网 IP（如 `192.168.1.5`），在手机浏览器访问 `http://192.168.1.5:8080` 即可在手机上自测刷卡！

#### 3. 部署到免费的 GitHub Pages (随时随地在线访问)
1. 在 GitHub 创建您的个人专属私有或公开仓库；
2. 绑定远程仓库并推送：
   ```bash
   git remote set-url origin https://github.com/<你的用户名>/<你的仓库名>.git
   git push -u origin main
   ```
3. 打开 GitHub 仓库页面 -> **Settings** -> **Pages** -> **Build and deployment** 下将 **Source** 切换为 **GitHub Actions**；
4. 仓库内置的 `.github/workflows/deploy-pages.yml` 将自动发布；在手机浏览器打开部署网址，点击 **添加到主屏幕**，即可像原生 App 一样随时自测！

## 🛠️ 常见问题解答 (FAQ)

### Q1: 运行脚本报编码错误或找不到 Python？
- **Python 找不到**：请确认已安装 Python 3.8 或更高版本，并在安装时勾选了 `Add python.exe to PATH`；
- **Windows 乱码**：本项目所有脚本已内置 UTF-8 控制台兼容层。若使用 PowerShell，可执行 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` 确保正常显示。

### Q2: 为什么我推送到 GitHub 后，找不到我的做题记录和错题？
- **这是特意设计的保护机制**！本项目遵循 Local-First 原则，`.gitignore` 会拦截所有非 `.template.md` 的真实做题笔记、错题和学情。您的隐私安全永远是第一位的。如果您需要多端备份做题记录，建议使用私有仓库（Private Repo）并按需调整 `.gitignore`。

### Q3: 考试科目不同怎么改？
- 本脚手架采用完全解耦设计。考数学一或三，只需在 `01-数学/AGENTS.md` 中把科目名和教材换掉；专业课考 408 计算机或管理学，只需在 `04-专业课/AGENTS.md` 中修改参考教材。看板构建引擎会自动提取新科目的考点与卡片！
