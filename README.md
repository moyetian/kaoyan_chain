## 📖 这是什么？

<p align="center">
  <img src="docs/assets/feature_comparison.svg" alt="传统 AI 对话与考研学习链对比" style="max-width:100%;" />
</p>

**考研学习链 (Kaoyan AI Study Chain)** 是一套面向考研学子的**数字化、工程化 AI 私人教师备考系统**。

传统使用大模型（ChatGPT、Claude、Gemini、DeepSeek 等）备考经常遇到四大痛点：
1. **幻觉与超纲**：AI 随性自编缺少标准答案的题目，或者派发超出大纲范围的偏题怪题；
2. **缺乏记忆与连续性**：多轮对话后 AI 遗忘你之前的薄弱考点、错题记录与复习节奏；
3. **缺乏采分点闭环**：直接给出终极答案，缺乏步骤分、公式分与“错因五分类”追查；
4. **缺少移动端自测工具**：碎片时间（排队、通勤、睡前）难以高效进行公式与核心考点默写。

本项目借鉴现代软件工程的成熟架构，将 **Agent 私教协议（AGENTS.md）**、**外置状态机记忆（External State）**、**白名单题源抽题门禁（Source Verification）** 与 **自动化轻量 Web 看板（Static Site Generator）** 相结合，帮助考研人构建属于自己的高纪律、零幻觉、稳拿基本盘的数字化私教系统。

## 🔒 隐私与防泄露机制（Local-First 原则）

本项目采用严格的 **Local-First（本地优先）** 隐私保护架构：
- 仓库内仅公开架构规范、教学协议与 `*.template.md` 空白模板文件；
- **个人隐私保护**：`.gitignore` 规则自动忽略您实际填写的个人学情文件（如 `今日任务.md`、`学员档案.md`、`当前进度.md`、`学情档案.md`）以及您每日在 `每日笔记/`、`每日作业/`、`错题本/`、`参考资料/` 下产生的所有私人做题记录与大体积 PDF；
- 无论您如何提交代码，您的个人复习进度、做题草稿、错题明细与大体积资料都**牢牢保留在本地，绝不会上传到 GitHub**。

## 🎭 四大私教辅导风格（按需切换）

每位考研学子的备考基础与性格特点各不相同，本项目在顶层协议 [`AGENTS.md`](AGENTS.md) 中原生内置了**四大可切换的私教辅导风格**，AI 私教将根据您的选择自动调整语气、批改尺度与讲解深度：

| 风格名称 | 核心特征 | 教学行为准则 | 适合人群 |
|---|---|---|---|
| 🛡️ **严格把关·保姆提分型**<br>*(Strict & Disciplined · 默认)* | 严苛阅卷人视角 | 严抓推导步骤，每步标注 `[+2分]` / `[-1分]`；计算失误或跳步零容忍；强制要求进行「错因五分类」追查并写入重做队列 | 自律性稍弱、易粗心马虎、计算失误频发、追求冲刺 120+ 高分 |
| ⚡ **高效应试·高频秒杀型**<br>*(High-Yield Hacker)* | 80/20 法则为王 | 剔除一切偏难怪题与低性价比考点；强化代入法、排除法、特征值秒杀法、政治帽子词口诀与英语主干速抓技巧；成块套用答题模板 | 在职备考、启动较晚、时间紧迫、急需短期内稳抓 80% 核心盘过线 |
| 🌱 **温和启发·减负鼓励型**<br>*(Encouraging Mentor)* | 降低挫败，微步提示 | 将综合大题拆解为 2-3 个微小提示；多用日常生活生动比喻解释抽象定理；即便答错也先肯定思考亮点，再温和指出盲区 | 跨考新手、容易焦虑内耗、面对难题容易畏难卡壳的同学 |
| 🧠 **深度原理·学霸溯源型**<br>*(Deep Conceptual Master)* | 追根溯源，融会贯通 | 引导学员从“命题人命制陷阱”的角度审视题干；追溯定理的几何意义与物理背景；启发学员推导底层定理并自制知识图谱 | 基础扎实、冲刺名校专业第一、渴望探究底层数学/工程本质的学霸 |

> 💡 **如何切换风格**：在运行 `python tools/init_workspace.py` 时直接按键选择，或随时在 [`AGENTS.md`](AGENTS.md) 的「当前激活辅导风格」一行中填入对应的风格名称即可生效！

## 📚 学习资料与考纲导入指引

要让 AI 私教做到“不超纲、零幻觉”，必须为私教挂载可靠的资料源。本项目提供三层清晰的资料挂载机制：

### 1. 资料存放目录（完全本地私密）
在运行初始化脚本后，项目已为数学、英语、政治、专业课创建了专属资料目录：
```text
01-数学/
├── 考试大纲.md     <-- [填入官方大纲知识点清单]（掌握/理解/了解）
├── 参考资料/       <-- [受 .gitignore 保护] 存放教材 PDF、习题册扫描件等
```

### 2. 向 AI 私教导入资料的 3 种推荐方式
1. **题号直考法（最推荐 · 零扫描成本）**：
   无需将整本厚书数字化。只需在每日报到时告知 AI 您手头的纸质书书名与题号：
   > *“老师，今天进行《李林880》一元微积分练习，请按第 12 页第 3 题考查我，先只出题干不要答案。”*
2. **考纲要点对齐法**：
   将您目标院校公布的官方考试大纲（或统考考纲）文本粘贴到各科根目录下的 `考试大纲.md` 中。AI 教师派题与判卷时会自动对照考纲，超出考纲范围的知识点会自动阻断并提醒您跳过。
3. **草稿拍照与手写识别法**：
   在草稿纸上解题完毕后，用手机拍照直接粘贴/上传到对话框中输入 `交作业`。具有多模态视觉能力的 Agent 会自动识别手写推导、圈出计算错误行并打分。

## 🤖 市面主流 AI Agent 工具接入指南

本项目采用标准开放的 Agentic Markdown 架构，原生适配市面上主流的各类 AI 智能体与客户端：

```
┌────────────────────────────────────────────────────────────────────────┐
│                        市面主流 AI Agent 接入生态矩阵                   │
├─────────────────┬─────────────────┬──────────────────┬─────────────────┤
│ Google          │ Cursor          │ Trae (字节跳动)   │ Cherry Studio   │
│ Antigravity     │ AI 代码/文本编辑器 │ 自适应 AI IDE    │ 桌面多模型聚合   │
├─────────────────┼─────────────────┼──────────────────┼─────────────────┤
│ WorkBuddy       │ VS Code + Roo   │ Claude Code      │ 网页端通用大模型 │
│ 桌面自动化工作流 │ 本地插件生态     │ 命令行 Agent     │ 浏览器零门槛使用 │
└─────────────────┴─────────────────┴──────────────────┴─────────────────┘
```

### 1. Google Antigravity (最推荐 · 原生支持)
- **特点**：官方全功能深度适配，支持全工作区感知、多智能体自动路由与任务调度。
- **使用方法**：直接在 Antigravity 中打开本仓库目录，在对话框输入 `学数学` 或 `数学报到`，AI 自动完成任务读取、批改与状态写回。

### 2. Cursor
- **特点**：AI-First 文本与代码编辑器，内置强大的 Composer (Ctrl+I) 自动编辑能力。
- **使用方法**：
  1. 项目根目录已内置 [`.cursorrules`](.cursorrules) 全局协议；
  2. 使用 Cursor 打开本项目目录；
  3. 快捷键 `Ctrl + L`（Chat）或 `Ctrl + I`（Composer）发送 `[科目]报到` 或 `交作业`。

### 3. Trae (字节跳动自适应 AI IDE)
- **特点**：针对国内考研用户网络体验极佳，中文提示词理解精准，内置智能 Builder 模式。
- **使用方法**：
  1. 使用 Trae 打开本项目工作区；
  2. 在右侧 Chat 侧边栏中开启 Agent / Builder 模式；
  3. 输入 `@workspace` 并发送口令，如 `@workspace 数学报到`，Trae 自动联动全库文件完成批改。

### 4. Cherry Studio (樱桃工作室 · 桌面多模型客户端)
- **特点**：国内极高人气的多大模型桌面端，聚合 DeepSeek-R1/V3、Claude 3.7、OpenAI o3-mini、Kimi、Qwen 等。
- **使用方法**：
  1. 打开 Cherry Studio，新建一个专属「考研私教助手」；
  2. 将本项目根目录 [`AGENTS.md`](AGENTS.md) 的全文内容复制粘贴到助手的「系统提示词 (System Prompt)」中；
  3. 在「知识库 (Knowledge Base)」板块中，点击「添加本地目录」，将本项目的 `01-数学`、`02-英语`、`03-思想政治理论`、`04-专业课` 文件夹添加为知识库；
  4. 提问时开启知识库引用，即可享受桌面端满血大模型调取个人笔记与考纲！

### 5. WorkBuddy (桌面工作流自动化智能体)
- **特点**：支持本地桌面环境调度与工作流编排，可实现定时自动更新看板。
- **使用方法**：
  1. 在 WorkBuddy 中建立「考研每日循环」工作流；
  2. 挂载本项目工作区路径；
  3. 将夜间脚本 `python tools/update_dashboard.py` 绑定为晚间复盘任务的自动触发动作。

### 6. VS Code (搭配 Roo Code / Cline / Continue 插件)
- **特点**：开源自由度高，支持配置本地 Ollama 或任何兼容 OpenAI 格式的第三方 API Key。
- **使用方法**：
  1. 安装 Roo Code 或 Cline 插件；
  2. 项目根目录已内置 [`.clinerules`](.clinerules)，插件会自动加载并注入作为顶层系统约束。

### 7. 网页端通用大模型 (ChatGPT / Claude / DeepSeek / Kimi / 豆包)
- **特点**：零安装门槛，任何手机、平板或网吧电脑的浏览器即开即用。
- **使用方法**：
  1. 在 ChatGPT 创建「Custom GPT」，或在 Claude 创建「Project」；
  2. 将 [`AGENTS.md`](AGENTS.md) 设置为 Instructions / Project Prompt；
  3. 每天复习时，将 `今日任务.md` 与题目图片发送到对话中，完成后让 AI 输出 Markdown 表格复制回本地保存。

## 💻 专有考研智能终端：`ky-cli` (类似 Claude Code 的独立私教)

如果您不想打开笨重的大型 IDE，本项目自带了一个专为考研学子研发的**轻量级专用终端私教工具（`ky-cli`）**。
- **纯 Python 标准库编写**：零 `pip install` 依赖，只要有 Python 即可秒开；
- **全模型 API 原生接入**：直接配置 DeepSeek (V3/R1)、智谱 GLM、通义千问、月之暗面 Kimi、OpenAI 或本地 Ollama；
- **多端聊天机器人桥接 (IM Bridge)**：支持连接**微信 (ClawBot/企微)**、**QQ (NapCat/OneBot)**、**钉钉**、**飞书**。

```
       ┌─────────────────────────────────────────────────────────┐
       │                ky-cli 专有终端私教 (ky.bat / ./ky)       │
       └────────────────────────────┬────────────────────────────┘
                                    │
           ┌────────────────────────┼────────────────────────┐
           ▼                        ▼                        ▼
    【极速交互 TUI】        【大模型直连 API】       【多端机器人推送与网关】
   像 Claude Code 一样    DeepSeek / Kimi / Qwen   微信 / QQ / 钉钉 / 飞书
   /math 切换数学私教     流式打字机逐字输出        /notify 一键推晨报到群
   /submit 步骤打分       零第三方依赖             ky serve 接收微信/QQ提问
```

### 1. 极速启动与日常交互
在工作区根目录下直接执行：
```bash
# Windows 用户直接输入：
ky
# 或者：python tools/ky_cli.py

# macOS / Linux 用户：
./ky
```

### 2. 常用终端斜杠指令
| 快捷指令 | 功能效果 | 核心使用场景 |
|---|---|---|
| `/math` | 瞬间切换至**数学私教**，自动重载数学大纲与错题档案 | 刷数学核心题型与步骤打分 |
| `/eng` | 切换至**英语私教**，加载真题阅读定位法与长难句库 | 拆解长难句、研读真题阅读 |
| `/pol` | 切换至**政治私教**，挂载核心速记与帽子词自测库 | 刷高频选择题与答题模板 |
| `/pro` | 切换至**专业课私教**，挂载官方教材知识图谱 | 大题背诵与教材课后题练习 |
| `/status` | 打印今日考研进度、各科目标分与研考倒计时 | 晨起第一眼掌握全局战役态势 |
| `/notify` | 一键将今日任务卡片广播推送到微信、QQ、钉钉、飞书群 | 晨间起床自动打卡提醒 |
| `/build` | 终端内直接重新编译本地与移动端自测看板 | 随时生成最新 HTML 看板 |
| `/config` | 交互式配置 API 服务商、API Key、模型名称与机器人 Webhook | 首次启动或切换模型时使用 |

### 3. 连接微信、QQ、钉钉、飞书聊天软件 (IM Bridge)
在终端运行 `ky config` 即可填入对应机器人的 Webhook：
- **微信 / 企业微信 / ClawBot**：填入群机器人 Webhook 地址；
- **钉钉**：填入钉钉群自定义机器人 Webhook 与加签 Secret；
- **飞书**：填入飞书群自定义机器人 Webhook；
- **QQ (OneBot 11 / NapCat)**：填入本地或服务器 OneBot HTTP 地址与目标群号。

#### 进阶玩法：启动双向接收网关 (`ky serve`)
```bash
# 启动本地 Webhook 接收网关（默认 8088 端口）
ky serve --port 8088
```
配合 cpolar 或内网穿透工具将该端口映射公网，在钉钉/微信/QQ 机器人后台配置该回调地址，即可实现在**微信群或 QQ 群中直接 @机器人 进行考研知识点问答、抽题与交作业**！

## 🚀 用户本地化部署与快速上手流程 (3 分钟开箱)

### 环境依赖
- **操作系统**：Windows、macOS 或 Linux
- **Git**（版本管理）
- **Python 3.8+**（无需安装任何 pip 第三方库，全部使用 Python 标准库）

### 第一步：获取项目模板

在终端或命令行运行：

```bash
# 克隆本仓库到本地
git clone https://github.com/moyetian/kaoyan_chain.git my-kaoyan-chain
cd my-kaoyan-chain
```

*(也可以直接在 GitHub 点击绿色 **Code -> Download ZIP** 下载压缩包解压使用)*

### 第二步：一键初始化本地工作区 (推荐)

项目内置了跨平台的交互式初始化引导工具：

```bash
# 运行初始化向导 (Windows / macOS / Linux 通用)
python tools/init_workspace.py
```

> [!TIP]
> 脚本将自动引导您：
> 1. 一键将四科 `_状态/` 目录中的 `*.template.md` 实例化为本地受保护的 `*.md` 工作文件；
> 2. 为各科目建立私密的 `参考资料/` 目录与 `考试大纲.md` 考纲清单；
> 3. 交互式选择**私教辅导风格（严格/秒杀/鼓励/溯源）**与**主要使用的 Agent 工具**；
> 4. 输入目标院校、专业与四科目标分数，自动写入 `AGENTS.md`；
> 5. 立即自动编译生成您的第一版专属移动端看板 `docs/index.html`。
> 
> *如果您希望跳过问答、使用默认配置快速启动，可执行：`python tools/init_workspace.py --quick`*

在您选用的 Agent 中直接输入口令开始复习：
1. **晨间报到**：发送 `数学报到` 或 `英语报到`，AI 根据前一日错题与今日规划派题；
2. **日间作答**：草稿纸解答后拍照或敲字提交，输入 `交作业`；

### 第四步：移动端自测看板查看与多端同步

#### 1. 本地直接预览
双击工作区中的 [`docs/index.html`](docs/index.html)，即可直接在任何现代浏览器中打开清新整洁的自测看板！

#### 2. 同局域网手机浏览 (无需云端)
在项目根目录下启动轻量级本地服务：
```bash
python -m http.server 8080 --directory docs
```
查看电脑的局域网 IP（如 `192.168.1.5`），在手机浏览器访问 `http://192.168.1.5:8080` 即可在手机上自测刷卡！

#### 3. 部署到免费的 GitHub Pages (随时随地在线访问)
1. 在 GitHub 创建您的个人专属私有或公开仓库；
2. 绑定远程仓库并推送：
   ```bash
   git remote set-url origin https://github.com/<你的用户名>/<你的仓库名>.git
   git push -u origin main
   ```
3. 打开 GitHub 仓库页面 -> **Settings** -> **Pages** -> **Build and deployment** 下将 **Source** 切换为 **GitHub Actions**；
4. 仓库内置的 `.github/workflows/deploy-pages.yml` 将自动发布；在手机浏览器打开部署网址，点击 **添加到主屏幕**，即可像原生 App 一样随时自测！

## 🛠️ 常见问题解答 (FAQ)

### Q1: 运行脚本报编码错误或找不到 Python？
- **Python 找不到**：请确认已安装 Python 3.8 或更高版本，并在安装时勾选了 `Add python.exe to PATH`；
- **Windows 乱码**：本项目所有脚本已内置 UTF-8 控制台兼容层。若使用 PowerShell，可执行 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` 确保正常显示。

### Q2: 为什么我推送到 GitHub 后，找不到我的做题记录和参考资料？
- **这是特意设计的保护机制**！本项目遵循 Local-First 原则，`.gitignore` 会拦截所有非 `.template.md` 的真实做题笔记、错题、学情以及放在 `参考资料/` 中的版权电子书与试卷。您的隐私安全与版权资产永远受到严密保护。

### Q3: 考试科目或专业不同怎么改？
- 本脚手架采用完全解耦设计。考数学一或三，只需在 `01-数学/AGENTS.md` 中把科目名和教材换掉；专业课考 408 计算机或管理学，只需在 `04-专业课/AGENTS.md` 中修改参考教材。看板构建引擎会自动提取新科目的考点与卡片！
