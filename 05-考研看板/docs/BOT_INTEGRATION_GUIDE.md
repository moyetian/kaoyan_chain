## 一、微信个人号：WeChat ClawBot 手机扫码直连（腾讯官方）

### 🌟 核心特色
- **零公网门槛**：**无需任何公网 IP，无需配置复杂的 Webhook**；
- **腾讯官方驱动**：由腾讯微信团队官方开源的 `@tencent-weixin/openclaw-weixin-cli` 插件提供支持；
- **手机扫码即连**：终端自动输出二维码，手机微信“扫一扫”确认授权，微信直接变成你的 24 小时贴身考研私教！

### 🚀 极速接入步骤

#### 第 1 步：环境自检
确保电脑已安装 Node.js（v18+）。打开终端检测：
```bash
node -v
npx -v
```
*(若未安装，可在 Windows 终端运行 `winget install OpenJS.NodeJS` 或前往 [nodejs.org](https://nodejs.org) 下载安装)*

#### 第 2 步：一键启动扫码连接
在考研终端中，直接运行以下任意一种方式：

**方式 A（考研终端内置指令）：**
```bash
ky clawbot
# 或
ky wechat
```

**方式 B（直接调用腾讯官方脚手架）：**
```bash
npx -y @tencent-weixin/openclaw-weixin-cli@latest install
```

#### 第 3 步：手机扫码授权
1. 终端窗口会自动渲染出一个 **微信登录二维码**；
2. 拿起手机打开微信 ➔ 点击右上角 **「扫一扫」** ➔ 扫描终端二维码 ➔ 点击 **「确认授权登录」**；
3. 终端提示 `WeChat Login Success!` 即表示连接建立！

#### 第 4 步：对接本地考研大模型接口
微信接收到的所有提问，将自动通过本地网关桥接：
- **OpenAI 兼容端点**：`http://127.0.0.1:8088/v1`
- **模型代号**：`kaoyan-tutor`（或 `kaoyan-math`、`kaoyan-eng`）
- **特点**：全自动挂载考研各科 `AGENTS.md` 顶层中枢协议、步骤赋分标准与 6 项核心解题技能！

## 二、钉钉群：自定义机器人双向对话

钉钉支持在群聊中直接 `@机器人 题目内容` 进行双向讲题答疑。

> [!TIP]
> **已彻底解决钉钉 5 秒超时难题**：
> 本系统已内置基于 `sessionWebhook` 的异步分发管道。收到钉钉呼入后，网关在 50ms 内快速握手，后台审题计算完毕后自动回传群聊，绝不会触发钉钉官方的“请求超时”错误！

### 🚀 接入步骤

#### 1. 开启公网穿透（获取公网回调 URL）
钉钉服务器位于阿里云，需要能访问到您本机的 `8088` 端口。使用免费穿透工具映射：
```bash
# 使用 cpolar:
cpolar http 8088
# 或 Cloudflare Tunnel (免费不限速):
cloudflared tunnel --url http://localhost:8088
```
得到穿透域名，例如：`https://kaoyan.cpolar.top`。

#### 2. 在钉钉群开启机器人回调
1. 打开电脑端钉钉 ➔ 进入考研备考群 ➔ 点击右上角 **「群设置」** ➔ **「智能群助手」**；
2. 点击 **「添加机器人」** ➔ 选择 **「自定义」** 机器人；
3. 安全设置建议勾选 **「加签」**，复制 Webhook 地址与加签 Secret；
4. 找到 **「机器人回调」** 区域，打开 **「开启」** 开关；
5. 在 **「POST 地址」** 中填入：
   ```text
   https://<你的穿透域名>/webhook
   ```
6. 点击保存。

#### 3. 保存配置与群内讲题
在终端运行 `ky config` ➔ 选择 `[3] 📱 机器人配置` ➔ `[3] 钉钉群`，输入 Webhook 地址和 Secret。

**群内艾特提问示例：**
> `@考研私教 学数学：请问极限保号性的核心定义是什么？有何几何意义？`
> `@考研私教 /calc limit (sin(x)-x)/x^3 as x->0`

## 三、飞书群：自建企业应用与事件订阅

飞书通过企业自建应用的“事件订阅”机制接收群聊与私聊提问。

### 🚀 接入步骤

#### 1. 创建飞书自建应用
1. 登录 [飞书开放平台 (open.feishu.cn)](https://open.feishu.cn)；
2. 点击 **「创建企业自建应用」** ➔ 填写名称（如“考研全科私教”）➔ 创建；
3. 进入应用详情页 ➔ 点击左侧 **「添加应用能力」** ➔ 选择添加 **「机器人」**。

#### 2. 配置事件回调与握手校验
1. 在左侧菜单点击 **「事件与回调」** ➔ **「事件配置」**；
2. 在 **「请求网址 (Encrypt Key 可不填)」** 处填入：
   ```text
   https://<你的穿透域名>/webhook
   ```
3. 点击保存。
   > [!NOTE]
   > 本系统已内置标准的 `url_verification` 握手应答，飞书页面将立即弹出 **“URL 校验成功”** 提示！
4. 点击下方 **「添加事件」** ➔ 搜索并勾选：
   - `接收消息 (im.message.receive_v1)`

#### 3. 发布应用与群内使用
1. 点击左侧 **「版本管理与发布」** ➔ 创建新版本并提交发布申请（企业自建应用直接秒审通过）；
2. 打开飞书客户端，把考研私教机器人拉进你的考研群或进行 1 对 1 私聊；
3. 在群内艾特机器人即可开始对话讲题！

## 四、QQ 群：NapCat / OneBot 11 本地极速模式

如果您更习惯在 QQ 备考交流，**NapCat QQ 机器人是体验最好的方案，且完全不需要外网穿透！**

### 🚀 接入步骤

1. 下载并运行 [NapCat QQ (或 LLOneBot)](https://github.com/NapNeko/NapCatQQ)；
2. 打开 NapCat Web 管理面板（通常为 `http://127.0.0.1:6099/web`）；
3. 进入 **「网络配置」** ➔ 点击 **「添加配置」** ➔ 选择 **「HTTP 事件上报」**；
4. 将上报 URL 设置为：
   ```text
   http://127.0.0.1:8088/webhook
   ```
5. 保存应用；
6. 在 QQ 群中 `@机器人 学数学：求导数`，私教大模型将在本地毫秒级响应并在群内艾特秒回！

## 五、免费外网穿透极速上手（cpolar / Cloudflare）

钉钉和飞书的云端服务器需要回调本地电脑，可通过以下两个免费工具打通外网访问：

### 选项 1：cpolar（国内直连，稳定快捷）
1. 访问 [cpolar.com](https://www.cpolar.com) 注册并下载客户端；
2. 打开终端运行：
   ```bash
   cpolar http 8088
   ```
3. 界面中显示的 `https://xxxx.cpolar.top` 即为公网地址，回调地址为 `https://xxxx.cpolar.top/webhook`。

### 选项 2：Cloudflare Tunnel（完全免费，不限速，无连接数限制）
1. 打开终端通过 winget 安装：
   ```bash
   winget install Cloudflare.cloudflared
   ```
2. 启动穿透：
   ```bash
   cloudflared tunnel --url http://localhost:8088
   ```
3. 终端会输出形如 `https://random-words.trycloudflare.com` 的网址，回调填 `https://random-words.trycloudflare.com/webhook` 即可。

## 六、企业微信群机器人（单向通知）

适用于企业微信考研群的每日晨报与待办任务定时推送：
1. 打开企业微信群 ➔ 点击右上角 ➔ **「添加群机器人」**；
2. 复制生成的 Webhook URL（如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxx`）；
3. 运行 `ky config` ➔ 选择 `[3] 机器人配置` ➔ `[2] 企业微信` 粘贴保存；
4. 每日清晨或运行 `ky notify` 时，今日任务与自测卡片将自动同步推送到群内。
