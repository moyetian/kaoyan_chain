| 辩证法的**总特征** | 联系的观点和发展的观点。 |

## 四、史纲（关键节点与帽子词）

| 帽子词 | 标准表述 |
|---|---|
| 近代以来中华民族最**伟大的梦想** | 实现中华民族伟大复兴。 |
| 中国近代史的**起点** | 1840 年鸦片战争。 |
| **新民主主义革命的开端** | 1919 年五四运动。 |
| **中国共产党成立的标志** | 1921 年中共一大（上海→嘉兴南湖）。 |
| **生死攸关的转折点** | 1935 年遵义会议。 |
| **全民族抗战的起点** | 1937 年七七事变；抗战胜利：1945 年。 |
| **新中国的成立** | 1949 年 10 月 1 日，标志着新民主主义革命取得基本胜利。 |
| **社会主义制度基本确立** | 1956 年三大改造基本完成。 |
| **改革开放的伟大开端** | 1978 年党的十一届三中全会。 |
| **中国特色社会主义进入新时代** | 党的十八大以来（2012 年起）。 |
| 中国共产党的**初心和使命** | 为中国人民谋幸福，为中华民族谋复兴。 |
