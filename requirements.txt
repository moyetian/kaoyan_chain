# 考研学习链 (Kaoyan AI Study Chain) · 依赖说明清单
#
# 【核心运行模式】：
# 考研学习链设计遵循 Local-first 原则：核心 REPL 交互、协议路由器、状态管理与
# 大模型通信基于 Python 3.10+ 标准库；终端富文本渲染（面板/表格/语义色）由
# 纯 Python 的 rich 提供（见下方「0. 终端富文本渲染」），无任何二进制扩展。
#
# 若需启用以下考研专有高级技能，可通过 pip 安装对应增强依赖：

# ── 0. 终端富文本渲染 (CLI REPL，核心依赖) ──
# tools/cli/repl/renderer.py 用 Panel/Table/Style 渲染状态大盘、指令面板与欢迎
# 横幅，属**必需**依赖（缺失时 REPL 无法启动）。纯 Python、MIT 许可、无二进制
# 扩展；自带 NO_COLOR 与非 TTY 降级（管道/重定向时不留转义码）。
rich>=13.0

# ── 1. 数学符号高精度验算技能 (math_verifier) ──
# 支持高阶导数、不定积分、微分方程通解、二次型正定性矩阵顺序主子式验算
sympy>=1.12

# ── 2. 历年真题与参考资料 PDF 抽取技能 (pdf_extractor) ──
# 支持从本地真题扫描件/教材 PDF 抽取指定页码并切分题号 (cryptography 用于 AES 权限位解密)
# [审查 P1/P7 说明] 版本兼容矩阵（实测）：
#   pypdf 6.x + cryptography 50  → 无警告（CI / 新装环境默认组合）；
#   pypdf 3.x + cryptography 46/47 → ARC4 弃用警告（CryptographyDeprecationWarning，
#     UserWarning 子类）；已由 pyproject filterwarnings 精确白名单（限定 pypdf 模块）
#     忽略，测试不判红；
#   pypdf 3.x + cryptography 48+ → ARC4 被移除，pypdf 3.x 导入即 ImportError
#     → 真题 PDF 提取不可用（doctor 会如实报"未安装"，装新版 pypdf 即恢复）。
#   故旧环境如遇 PDF 提取失效，请 `pip install -U pypdf` 升级到 6.x。
pypdf>=3.17.0
cryptography>=41.0.0

# ── 3. 视觉解题与拍照批改增强技能 (vision_solver) ──
# 支持剪贴板截图处理、草稿图尺寸优化与 Base64 编码
Pillow>=10.0.0

# ── 4. 本地离线 OCR 文本识别技能 (可选) ──

rapidocr-onnxruntime>=1.3.0

# ── 5. 招考情报与高校注册表解析技能 (intelligence/registry) ──
# 支持高校考研专业目录 YAML 解析与多源证据比对
PyYAML>=6.0
# ── 6. 桌面视觉交互与管理界面 (GUI) ──
# 基于 Qt/PySide6 构建全科备考看板、可视化做题与真题库切片检索
# 上限必须 <6.12：6.12.0（2026-10-08 时 PyPI 最新）存在「退出阶段段错误」
# 回归 —— pytest 全量通过后、解释器关闭期在纯 C++ 侧崩溃（POSIX exit 139 /
# Windows exit 1，faulthandler 无 Python 帧）。最小复现（MainWindow 创建/关闭
# ×2）实测 6.12.0 崩 7/10 次、6.11.2 为 0/10；CI 全平台 9/9 红（同一工作流
# 此前装 6.11.2 时 9/9 绿）。待上游发布修复版并实测后，再放开上限。
PySide6>=6.6.0,<6.12
