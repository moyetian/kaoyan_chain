# 04-专业课 · 考试大纲（待生成）

本文件应当由系统依据你的**目标院校 + 报考专业**自动生成，用于：

1. 为 AI 私教锁定「绝不超纲」的命题范围；
2. 支撑知识图谱（`ky map`）、靶向组卷（`ky compose`）与同源变式检索（`ky variant`）。

## 如何生成

```bash
# 1. 执行初始化向导，填入目标院校与报考专业
python tools/init_workspace.py

# 2. 或在已完成配置后重建考纲
ky plan
```

生成后，本文件会被替换为你的专业课考纲要点清单（含「掌握 / 理解 / 了解」三级要求标注）。
